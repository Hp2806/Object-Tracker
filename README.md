# Color-Based Object Tracking using OpenCV

A real-time object tracking project built with Python and OpenCV.
The program detects a specific colored object through the webcam and draws
a bounding box around it in real time using HSV color segmentation.

## Features

- Real-time object tracking through webcam
- Color detection using HSV color space
- Contour detection to identify object boundaries
- Bounding box rendering around detected object
- Adjustable color range and size threshold

## Technologies Used

- Python
- OpenCV
- NumPy
